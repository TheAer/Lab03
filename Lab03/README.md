# Лабораторна робота №3. Нездатні до змін структури даних (immutability) у Python

**Варіант 3:** Студентська успішність.

## Опис завдання
Перетворено модель обліку успішності студентів на незмінні структури даних Python:
- `CourseResult` та `Student` реалізовано як `@dataclass(frozen=True, slots=True)`;
- оцінки зберігаються у кортежі `tuple[CourseResult, ...]`, навички — у `frozenset[str]`, профіль — у `MappingProxyType`;
- усі зміни стану оформлено як pure updates через `dataclasses.replace` без мутації вихідних об'єктів;
- додано кешування обчислення зваженого балу GPA через `@functools.lru_cache` та порівняння продуктивності.

## Переваги та накладні витрати незмінності
- **Переваги:** гарантована відсутність прихованих мутацій, референтна прозорість, безпечне повторне використання підструктур (structural sharing), можливість кешування результатів на незмінних `tuple`.
- **Накладні витрати:** створення нового об'єкта при кожному оновленні та необхідність копіювати словник перед обгортанням у `MappingProxyType` (який також робить `Student` нехешованим).
